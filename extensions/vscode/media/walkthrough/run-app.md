## Run your app

Start your development server the way you always do, for example in the VS Code terminal:

```
npm run dev
```

Localians looks for apps on this computer's `localhost` only, on common ports such as 3000 (Next.js), 5173 (Vite),
4200 (Angular) and 8000 (Django), and the ports your project uses. It never starts anything for you.
